# Arguments and Options

A command name alone is often not enough. You also tell the command
*what* to work on and *how* to behave. Extra words after the name are
**arguments**. Arguments starting with a dash are **options**, and they
change how the command works.

This module introduces two friendly practice partners: `seq`, which
prints sequences of numbers, and `date`, which prints the current date
and time. They are small tools, but the argument and option habits you
build on them apply to every command you will ever run.
